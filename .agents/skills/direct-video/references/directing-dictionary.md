# Directing dictionary

This starter vocabulary names what motion communicates. Entries are implementation-agnostic and begin at `candidate` confidence until rendered evidence supports promotion.

## Reveal

- Communicates: Previously unavailable information becomes perceivable.
- State change: concealed, occluded, blurred, cropped, or undifferentiated -> visible and legible.
- Attention path: concealment boundary -> emerging subject -> revealed implication.
- Variants: mask, draw-on, focus, unfold, spotlight, deblur.
- Fails when: The revealed information changes nothing for the viewer.

## Assemble

- Communicates: Separate parts form a system, object, or argument.
- State change: independent pieces -> meaningful whole with visible relationships.
- Attention path: parts -> connection points -> completed structure.
- Variants: snap, converge, stack, wire, cluster, tessellate.
- Fails when: Parts arrive without showing why they belong together.

## Trace

- Communicates: One subject moves through a process or environment.
- State change: location or ownership changes while subject identity persists.
- Attention path: subject -> next boundary -> subject after crossing.
- Variants: packet path, timeline cursor, route, lineage, cause chain.
- Fails when: The subject changes appearance so much that continuity is lost.

## Gate

- Communicates: Progress depends on a named authority, rule, or threshold.
- State change: blocked -> evaluated -> permitted or rejected.
- Attention path: approaching subject -> authority -> boundary -> outcome.
- Variants: approval, authorization, validation, threshold, rate limit.
- Fails when: The authority is unnamed or the state depends on color alone.

## Compare

- Communicates: Two or more options differ on a shared dimension.
- State change: isolated alternatives -> aligned evidence -> visible distinction.
- Attention path: common criterion -> option A -> option B -> deciding difference.
- Variants: split screen, overlay, synchronized timelines, matrix, before and after.
- Fails when: Layout, scale, or timing makes the comparison unfair.

## Transform

- Communicates: One state becomes another through a meaningful operation.
- State change: source form -> intermediate evidence -> destination form.
- Attention path: invariant feature -> changing property -> new state.
- Variants: morph, reflow, dissolve and replace, recomposition, state machine.
- Fails when: No invariant feature preserves object identity.

## Accumulate

- Communicates: Repeated additions create scale, pressure, proof, or complexity.
- State change: sparse -> progressively dense or weighted.
- Attention path: first unit -> repeated rule -> emergent total.
- Variants: stack, counter, trail, pile, graph growth, repeated marks.
- Fails when: More objects appear without a readable accumulation rule.

## Rank

- Communicates: Items acquire an order under a named criterion.
- State change: unordered set -> measured movement -> stable order.
- Attention path: criterion -> decisive values -> final ordering.
- Variants: race, sort, ladder, tier, priority queue.
- Fails when: Motion implies importance before the criterion is shown.

## Focus

- Communicates: One element becomes the current subject while context remains available.
- State change: equal salience -> selective emphasis -> return or handoff.
- Attention path: context -> emphasized subject -> relevant relation.
- Variants: camera push, spotlight, desaturation, scale contrast, rack focus.
- Fails when: Everything else disappears and the relationship is lost.

## Balance

- Communicates: Competing benefits, costs, or forces must be judged together.
- State change: separate claims -> shared scale -> equilibrium or decisive tilt.
- Attention path: force A -> force B -> pivot or decision rule.
- Variants: physical scale, weighted axis, tension line, tradeoff matrix.
- Fails when: Visual weight is decorative or does not correspond to the argument.

## Fracture

- Communicates: A system, assumption, or object stops behaving as one whole.
- State change: coherent -> stressed -> separated or failed.
- Attention path: original whole -> stress point -> resulting pieces.
- Variants: split, crack, branch, desynchronize, error cascade.
- Fails when: Destruction is spectacle without a named cause or consequence.

## Resolve

- Communicates: Earlier uncertainty collapses into a stable answer or rule.
- State change: open loop -> decisive evidence -> compressed final model.
- Attention path: recalled opening motif -> changed interpretation -> final state.
- Variants: return, lock, simplify, close loop, reveal rule.
- Fails when: The close introduces a new thesis instead of paying off the opening.

## Hand off

- Communicates: Responsibility, attention, data, or energy moves from one owner to another.
- State change: owner A active -> transfer event -> owner B active.
- Attention path: sender -> transfer object -> receiver -> receiver action.
- Variants: packet, baton, cursor, light pulse, matched gesture, audio bridge.
- Fails when: Ownership changes without a visible transfer event.

## Loop

- Communicates: A result feeds another pass, or the ending recontextualizes the beginning.
- State change: linear progress -> return path -> changed starting condition.
- Attention path: output -> return connection -> updated input.
- Variants: feedback loop, iteration, retry, cyclical process, seamless social loop.
- Fails when: The return path implies repetition but no state has changed.

## Combining primitives

Combine verbs only when the viewer can parse their order. Useful chains include:

- reveal -> trace -> gate -> hand off;
- assemble -> focus -> transform -> resolve;
- compare -> rank -> resolve;
- accumulate -> fracture -> diagnose;
- trace -> loop -> transform.

Record the chain in the beat action order. Do not hide it inside a broad instruction such as "make this dynamic."
