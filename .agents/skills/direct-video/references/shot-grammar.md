# Shot grammar

Use this reference to turn beats into precise, editable choreography.

## Addressing

Use stable IDs throughout direction, code, stills, and review:

- `B03`: beat 3;
- `B03.S02`: shot 2 inside beat 3;
- `B03.S02.E04`: element 4 inside that shot;
- `B03.A02`: audio event 2 inside that beat.

IDs identify conceptual units. Do not renumber unaffected units during revision. Add a suffix or record a replacement when insertion is necessary.

## Beat contract

Every beat should specify:

- job: the one inference, feeling, or decision this beat creates;
- question in: what remains unresolved when the beat begins;
- state in: visible elements and relationships already present;
- action chain: the ordered meaningful changes;
- state out: what is now visible or known;
- narration: spoken job and exact lines when available;
- duration range: conceptual estimate before frame planning;
- handoff: the visual or audio feature that carries into the next beat.

If the state out does not differ meaningfully from the state in, the beat is probably exposition without visual work.

## Shot sentence

Write each shot as:

`subject + meaningful action + spatial relation + attention change + exit condition`

Example:

`The request packet crosses the host boundary, pauses at the closed approval gate, becomes the only saturated object, and exits only after the gate opens.`

This is more useful than "animate a packet left to right" because it states causality and attention.

## Directing dimensions

| Dimension | Choices | What it controls |
| --- | --- | --- |
| Subject | text, object, person, interface, diagram, data, environment | What the viewer tracks |
| Action | reveal, assemble, trace, compare, transform, accumulate, gate, focus, rank, balance, fracture, resolve | What meaning changes |
| Space | enter, exit, cross, orbit, stack, split, converge, contain, occlude | How relationships become visible |
| Camera | lock, pan, push, pull, track, reframe, rack focus, parallax | How attention and scale change |
| Time | anticipate, strike, settle, hold, overlap, interrupt, echo | How rhythm communicates importance |
| Transition | continue, match, replace, wipe, dissolve, cut, collapse, expand | How one state becomes the next |
| Audio | narrate, accent, bridge, duck, pause, pulse, resolve | How sound confirms or redirects attention |

These are semantic choices. The build layer maps them to coordinates, masks, springs, cuts, or components.

## Choreography rules

- Give the viewer one primary attention target at a time.
- Let simultaneous motion express a real coupling. Otherwise stagger it.
- Preserve spatial meaning. A boundary, lane, scale, or direction should not change casually between shots.
- Use anticipation before a consequential event and a hold after it.
- Make exits cheaper than entrances unless the disappearance is the point.
- Let transitions preserve an object, shape, sound, direction, or idea when continuity matters.
- Record what remains static. Negative motion is part of direction.
- Keep text, narration, and the active visual from competing for the same cognitive moment.

## Shot audit

For each shot, ask:

1. What changes for the viewer?
2. Where should the eye be before, during, and after the change?
3. Which exact event causes the next event?
4. What survives into the next shot?
5. Could this shot be removed without losing meaning or rhythm?
