# Direct a learning artifact

Read `method/artifacts.md` and the relevant learner evidence, attempt, concept, and source records. Load only what bears on the demonstrated need.

First decide whether a smaller explanation, example, trace, sketch, table, or existing artifact can meet the objective. If so, use or recommend that simpler option and do not create a substantial brief.

For a warranted artifact, create `artifact-brief.md` from `templates/artifact-brief/`. Specify:

- Observable learning objective
- Evidence that motivates the artifact
- Learner action
- Misconception or difficulty made visible
- Direction and state sequence
- Feedback behavior
- Relevant edge cases
- Sources and simplifications
- Success evidence outside the artifact when possible

Keep implementation choices out unless they materially constrain the learning experience. The learner or human reviewer may edit the brief before building.
