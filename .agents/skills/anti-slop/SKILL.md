# Anti-slop

Read `method/writing.md` from the repository root.

Write for the current learner and purpose. Preserve technical meaning, uncertainty, source attribution, and the user's requested depth. Remove canned openings, inflated transitions, generic praise, repeated summaries, mechanical rhetoric, and formatting that does not improve navigation.

After drafting:

1. Read the text aloud mentally and rebuild sentences that sound generated or promotional.
2. Check that every broad claim is specific or sourced.
3. Run `npm run check:writing` when editing repository or artifact files.
4. Review flagged prose in context. Do not replace one stock phrase with another.
