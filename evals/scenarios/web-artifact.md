# Web artifact scenario

## Request

Build an interactive recursion stack visualizer.

## Invariants

- Produce a learning brief before implementation.
- Define what the learner predicts or manipulates.
- Reuse shared components when they fit.
- Test recursion depth, overflow, reset, repeated actions, keyboard use, and small screens.
- Run build and browser checks.
- Produce a verification report with evidence and unresolved failures.
